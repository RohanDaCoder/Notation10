# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
tag-based semantic version releases.

## [Unreleased]

### Added

- Clean-room reverse-engineering report (`docs/re/REPORT.md`) and roadmap.
- Multi-crate Cargo workspace scaffold (`notation`, `notation-core`,
  `notation-storage`, `notation-ui`, `notation-updater`).
- CI workflow: rustfmt + clippy + tests + release builds (Linux/Windows).
- Tag-based release workflow with checksummed artifacts.
- Iced prototype: multi-page whiteboard canvas, pen/highlighter/eraser,
  shape tools (rectangle, ellipse, line, arrow), text tool, page panel,
  undo/redo, and `.enbx` persistence.

## [0.2.0] — 2026-11-26

### Changed

- **GUI framework migrated from Iced to Tauri 2** (clean-room port continues;
  see `docs/ARCHITECTURE.md` for the new crate graph).
  - New `notation-tauri` crate: Tauri shell, command layer, native file
    dialogs (`tauri-plugin-dialog`), updater side effects, NSIS bundling.
  - New `notation-ipc` crate: the entire application session (tools, board
    gestures, pages, file operations, settings, updater bookkeeping) as
    pure, unit-tested Rust — ported one legacy message at a time.
  - `notation-ui` is now front-end agnostic design tokens (no Iced
    dependency); the webview consumes them via the `design_tokens` command.
  - `notation-updater` speaks the new `latest.json` release manifest
    protocol (per-platform artifact URL + SHA-256) in addition to the
    legacy `SHA256SUMS.txt` flow.
  - The Iced GUI crate (`notation`) was removed; its renderer and gesture
    semantics were ported to the webview front end (`ui/`, dependency-free
    ES modules with a browser mock backend for harness testing).
- Smart-shape recognition moved into `notation-core` (shared by every front
  end, now with its own unit tests).
- CI installs the webkit2gtk 4.1 stack on Linux; the release workflow
  builds the Windows NSIS installer via the Tauri CLI and publishes it with
  `SHA256SUMS.txt` + `latest.json` (tag-based, via `gh`).

### Fixed

- Figure creation and select-erase now record undo checkpoints (they were
  silently non-undoable in the Iced prototype).
- Page navigation no longer creates undo entries or marks the document
  dirty.
- The highlighter renders as a translucent fat stroke (the legacy fill
  could render thin lines invisibly).
- Status messages ("Saved successfully", update results, …) are now visible
  in the update bar; they auto-dismiss.

### Added

- Original application icon set (generated by `scripts/gen_icons.py`).
- `ui/js/mock.js`: in-browser mock backend implementing the full command
  surface for development and automated verification without a native build.

## [Unreleased]

### Added

- Crash-recovery prompt at startup: autosaved snapshots found in the
  recovery directory are offered with the original's wording ("The
  following document is not closed normally at the previous time:") and
  can be opened (as an unsaved document) or deleted; keyboard shortcuts
  are suppressed while the dialog is open, matching the legacy modal
  behavior. The mock backend can seed offers for harness testing.
